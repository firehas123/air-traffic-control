# Air Traffic Control (working title)

An original top-down 2D aircraft-routing game. The player draws flight paths to land aircraft safely and avoid collisions.

- Platforms: mobile first (Android, then iOS). PC and consoles later.
- Engine: Unity 2D with C# (proposed, not yet confirmed).
- Offline-first. No accounts and no backend in the first release.
- First release: Island Airport with ten levels, an endless mode, a daily level and one optional supporter purchase. No advertising.

The game title is still open, so this repository uses the working title.
